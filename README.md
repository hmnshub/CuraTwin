# CuraTwin
CuraTwin 🧬🤖 is a personalized Digital Health Twin that converts raw lab reports and prescriptions into proactive self-care. Built with React, FastAPI, and MongoDB Atlas, it uses OCR, NLP, and a Closed-Domain RAG pipeline to power vital dashboards and a conversational AI grounded strictly in your medical history. 🏥📈
